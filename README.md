# Apresentação EcoSphere

Apresentação do TCC de Bruno Soares de Souza, com 13 slides em HTML, CSS e JavaScript.

## Abrir

Abra `apresentacao/index.html` no navegador. As fontes e imagens são locais.

- Setas, espaço e Page Up/Down: navegar.
- `f`: tela cheia.
- `n`: abrir as notas editáveis em uma janela separada.

As edições das notas são salvas somente no navegador e endereço em que foram feitas. Elas não alteram o HTML nem são sincronizadas com o GitHub.

## Publicar na Vercel

Importe este repositório e mantenha **Root Directory** na raiz (`./`).
O arquivo `vercel.json` define o preset **Other**, nenhuma etapa de build e a saída em `apresentacao`.

Não são necessárias variáveis de ambiente.
